# c3 — 空标题保存报字段错误且对话框不关闭

Status: resolved

## 验收标准

空标题保存 → 字段错误提示「标题不能为空」，且对话框不关闭。

## 结论

**通过。**

## 证据

打开新建对话框（标题留空）后点保存：

| 断言 | 实测 |
| --- | --- |
| 对话框是否关闭 | `open = true` —— **未关闭** ✓ |
| 标题字段错误文案 | `标题不能为空` —— 与 `server/items.js:30` 的文案一致 ✓ |
| 错误落点 | 出现在 `#item-dialog [data-error-for="title"]`，即标题字段下方，**不是** toast ✓ |
| toast | 空（错误走了字段而非全局提示，符合预期）✓ |

同时确认了对话框的默认值与可选值：

- 起始/截止日期默认均为今天 `2026-09-17`
- 标签下拉为白名单五项（`工作/个人/会议/出差/紧急`）外加「（无标签）」
- `owner` 下拉对 `admin` 可见且默认选中 `admin`（`canAssign` 为真）

## 一处方法学说明

首次记录时打印的 `title value = null` **不是真空值**，而是 `locator.inputValue()` 在 IAB 中不存在、表达式退化为 `null` 所致。空标题这一事实由快照佐证：`textbox "要做什么"` 无内容。后续读数已改用 `getAttribute("value")`。

## 复现

点 `#btn-new` → 不填标题直接点 `[data-act="save"]` → 读 `[data-error-for="title"]`。
