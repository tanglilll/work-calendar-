# c2 — 新建事项后日历出现 `owner: 标题` 色块

Status: resolved

## 验收标准

对话框 → 保存 → 日历出现 `owner: 标题` 色块。

## 结论

**通过。**

## 证据

以 `admin` 登录一次性实例，经界面新建标题为 `验证事项C2` 的事项：

- 保存后 `#item-dialog` 的 `open` 由 `true` 变 `false`（对话框正常关闭）
- `#grid [data-item-id]` 计数 `0 → 1`；块文案为 `admin: 验证事项C2`，落在 **17 号格**（今天 = 2026-09-17）
- 块的 `title` 属性：`admin: 验证事项C2（2026-09-17 → 2026-09-17）`
- 颜色由系统分配，非手选：`style="background:hsl(0 68% 74%)"`
- 侧栏「今日任务」计数 `0 → 1`，并列出该事项与 `admin · 2026-09-17 → 2026-09-17`

## 附带确认（非缺陷）

「今日任务」与「截止提醒 · 今天截止」**同时**计为 1。这正是交接文档 §9.3 与 README「侧栏三个面板的口径」说明的刻意重叠，实测与文档一致。

## 复现

点 `#btn-new` → 填 `input[name="title"]` → 点 `[data-act="save"]`。点击方式见 `spec.md`。
